CodeAlpha Task Automation





Project Description

\-------------------



A Python automation program that extracts email addresses from a text file and saves them to another file.



Features

\--------



\- Reads text from `input.txt`.

\- Finds email addresses using regular expressions.

\- Removes duplicate email addresses.

\- Saves extracted emails to `emails.txt`.

\- Handles a missing input file.



Technologies Used

\-----------------



\- Python

\- Regular expressions

\- File handling



How to Run

\----------



1\. Install Python.

2\. Place text containing email addresses in `input.txt`.

3\. Open the project folder in PowerShell.

4\. Run `python main.py`.

5\. Check `emails.txt` for the extracted email addresses.
